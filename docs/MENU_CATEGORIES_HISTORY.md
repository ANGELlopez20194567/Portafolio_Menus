# Historial de categorías de menú

Este documento conserva la taxonomía del portafolio y funciona como referencia para redactar fichas técnicas futuras. Los nombres y alcances vigentes deben copiarse desde la versión más reciente de este historial.

## Versión vigente — 2026-08-15

| N.º | Categoría | Funciones incluidas |
| --- | --- | --- |
| 1 | **Classic Menu** | Categorías; fotos; descripciones; precios; animaciones suaves; diseño premium. |
| 2 | **Interactive Menu** | Platillos con interacción; fotografías grandes; hover/tap; transiciones; animaciones al hacer scroll; información desplegable. |
| 3 | **Smart Menu** | Buscador; filtros; vegetariano/vegano; alérgenos; picante; ingredientes; rango de precios. |
| 4 | **Customizable Menu** | Elegir ingredientes; elegir tamaño; extras; sustituciones; precio dinámico. |
| 5 | **Menu + Reservations** | Menú; disponibilidad; fecha y hora; número de personas; reservación; confirmación. |
| 6 | **Restaurant Experience** | Menú completo; historia del restaurante; chef; galería; ubicación; horarios; reservaciones; multidioma. |

### Cambio registrado

Se reemplazaron las categorías anteriores de la portada —Menú interactivo, Menú de pedidos, Menú informativo, Menú con reservas y Menú estático— por seis categorías con nombres comerciales y alcances funcionales definidos.

### Regla para fichas técnicas

Cada ficha técnica debe incluir como mínimo: nombre exacto de la categoría, objetivo, funciones incluidas, funciones opcionales, contenido requerido del restaurante, dependencias, criterios de aceptación, consideraciones responsive y fecha de elaboración. Si una categoría cambia, se añadirá una nueva versión fechada a este archivo sin sobrescribir el registro anterior.
