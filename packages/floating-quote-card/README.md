# Floating quote card

Componente reutilizable para todas las demos del portafolio. Permanece visible durante el scroll, se puede arrastrar y minimizar.

```html
<script type="module" src="../../packages/floating-quote-card/quote-card.js"></script>
<quote-card
  title="Classic Menu"
  description="Descripción comercial"
  features="Categorías,Precios,Diseño responsive"
  href="#cotizar">
</quote-card>
```

Los atributos `label`, `title`, `description`, `features`, `cta` y `href` permiten adaptar el contenido sin duplicar estilos ni comportamiento.
