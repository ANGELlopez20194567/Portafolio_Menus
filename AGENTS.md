# AGENTS.md

## Proyecto

Este repositorio contiene una colección de menús digitales
y experiencias web para restaurantes.

## Reglas

- No modificar archivos fuera del proyecto.
- No colocar API keys en el código.
- No colocar contraseñas en el repositorio.
- Utilizar variables de entorno para secretos.
- Reutilizar componentes cuando sea posible.
- Cada proyecto debe tener documentación.
- No eliminar archivos existentes sin autorización.
- Antes de realizar cambios grandes, explicar qué se modificará.
- Mantener los proyectos independientes cuando sea necesario.
- Priorizar diseño responsive.
- Probar los cambios antes de considerarlos terminados.

## Arquitectura

Los proyectos individuales deben poder desarrollarse
sin romper los demás proyectos.

## Seguridad

Nunca introducir:
- contraseñas
- tokens
- API keys
- credenciales
- información personal real

en archivos versionados.
